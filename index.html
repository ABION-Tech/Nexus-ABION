About n8n — you don't need it

n8n is an optional automation tool. All core emails work without it — the Apps Script backend sends Gmail directly on a daily schedule. n8n is only needed if you want Slack notifications, WhatsApp alerts, or other integrations in future. The "n8n Webhook Triggers" toggle simply adds a secondary ping to n8n if you ever set it up. Leave it ON but ignore it for now — it silently skips if no URL is configured.
